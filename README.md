## 📌 Project Overview
The **AI Project Topic Recommender** matches students with tailored capstone and internship project topics using Natural Language Processing (NLP), **TF-IDF vector space modeling**, and **Cosine Similarity matching**.

---

## ✨ Features Implemented
* ✅ **Student Interest Profile:** Input interface for skills, career aspirations, and domain filters.
* ✅ **Project Topic Database:** In-memory repository of multi-domain AI topics (NLP, CV, ML, GenAI).
* ✅ **Text Preprocessing & Tokenization:** Case-normalization, special character removal, and English stopword filtering.
* ✅ **TF-IDF Vectorization:** Numerical vector space conversion of student profiles and project keywords.
* ✅ **Cosine Similarity Matching:** Dynamic similarity measurement ranking top recommendations.
* ✅ **Top-N Results Engine:** Selectable Top-3, Top-5, or complete ranked topic lists.
* ⭐ **Bonus Deliverables:** Topic Clustering, Trend Analysis, Difficulty Level Filtering, Chart.js Visualization, and Python Flask REST API.
